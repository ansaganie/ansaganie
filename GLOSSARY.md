# Glossary

Canonical vocabulary for the personal website and live CV project.

### Live CV
A web-based, interactive curriculum vitae designed for both online viewing and ATS-compliant document parsing, with direct export capability to PDF.

### Overview Page
The primary summary view highlighting professional identity, core engineering competencies, impact summary, and featured projects.

### Timeline Page
The chronological career record detailing past roles, achievements, education, industry certifications, honors, and professional recommendations.

### Profile README
The repository's root `README.md` displayed publicly on the user's GitHub profile (`github.com/ansaganie`), kept aligned with the live CV overview.

### Locale
A supported language variant (`en`, `ru`, `kk`) that determines the UI copy and localized resume content under explicit path routes (`/`, `/ru`, `/kk`).
